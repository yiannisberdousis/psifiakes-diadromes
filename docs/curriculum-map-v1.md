# Ψηφιακές Διαδρομές — Curriculum Map v1

## Αρχές σχεδιασμού

- Κάθε τάξη έχει αυτόνομη μαθησιακή διαδρομή.
- Η ίδια θεματική επανέρχεται σπειροειδώς με αυξανόμενη δυσκολία.
- Κάθε ενότητα περιέχει 4–6 βασικές δραστηριότητες και προαιρετικές επεκτάσεις.
- Στο τέλος κάθε ενότητας υπάρχει σύντομο anonymous quiz με άμεση ανατροφοδότηση.
- Κάθε δραστηριότητα χαρακτηρίζεται από τύπο, χρόνο, δυσκολία και εργαλείο.
