# Dimpapp Content Audit — v1

## 1. Βασική αρχιτεκτονική που εντοπίστηκε

Το Dimpapp οργανώνει το περιεχόμενο ταυτόχρονα με δύο λογικές:

1. **Κατά ηλικιακή ομάδα**: Α΄–Β΄, Γ΄–Δ΄, Ε΄–ΣΤ΄.
2. **Κατά θεματική** μέσω του κεντρικού menu: Η/Υ, εφαρμογές γραφείου, προγραμματισμός, ρομποτική, εκπαιδευτικό υλικό, διαδίκτυο, ζωγραφική.

Αυτό δίνει μεγάλο εύρος περιεχομένου αλλά δημιουργεί επαναλήψεις και δύσκολη πλοήγηση.

## 10. Τι αλλάζουμε

- μία δραστηριότητα = μία εγγραφή περιεχομένου
- ξεχωριστή διαδρομή για κάθε τάξη
- θεματικά φίλτρα αντί για διπλές σελίδες
- σταθερό template δραστηριότητας
- metadata: grade, topic, duration, difficulty, type, tool
- σαφής μαθησιακή progression
- λιγότερα άσχετα entertainment links μέσα στον βασικό κορμό
- quiz ως μέρος της μαθησιακής ακολουθίας και όχι μόνο ως ξεχωριστή αποθήκη
