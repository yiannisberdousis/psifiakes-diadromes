# Ψηφιακές Διαδρομές

Εκπαιδευτική πλατφόρμα για το μάθημα ΤΠΕ στο Δημοτικό.

## Στόχος
Οργάνωση μαθησιακών διαδρομών ανά τάξη (Α΄–ΣΤ΄ Δημοτικού) και ανά θεματική, με δραστηριότητες, quizzes, παιχνίδια, προγραμματισμό, ρομποτική και ψηφιακή ασφάλεια.

## Τεχνολογία
- Astro
- Markdown/MDX content
- GitHub Pages

## Τοπική εκτέλεση
```bash
npm install
npm run dev
```

## Παραγωγή
```bash
npm run build
```

Το deployment γίνεται αυτόματα μέσω GitHub Actions.
